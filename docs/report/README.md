# Template เล่มรายงานโครงงานคอมพิวเตอร์ (v2)

สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

รูปแบบทั้งหมดเป็นไปตาม "คู่มือการจัดทำเอกสารโครงงานคอมพิวเตอร์" ของสาขาวิชา ได้แก่ ปก ขอบกระดาษ ฟอนต์ TH Sarabun New ขนาดตัวอักษร ระยะบรรทัด หัวข้อ ตาราง ภาพ สารบัญ เลขหน้า และรูปแบบเอกสารอ้างอิง นักศึกษาจึงเขียนเฉพาะเนื้อหาได้ทันที

ดูตัวอย่างเล่มฉบับสมบูรณ์ที่เขียนด้วย template นี้ได้ใน `Example_A_SystemDev_Project_2026_v2.zip` (โครงงานพัฒนาระบบ 82 หน้า)

## เริ่มใช้งาน

**Overleaf**

1. New Project > Upload Project > เลือกไฟล์ `Template_Project_2026_v2.zip`
2. Menu > Settings > Compiler = **XeLaTeX** (สำคัญ: pdfLaTeX ใช้ไม่ได้)
3. กด Recompile (Overleaf เรียก biber สำหรับเอกสารอ้างอิงให้อัตโนมัติ)

**เครื่องตนเอง** (TeX Live 2023 ขึ้นไป หรือ MiKTeX)

```
latexmk main.tex
```

ไฟล์ `.latexmkrc` กำหนดให้ใช้ XeLaTeX และ biber แล้ว

## ตัวเลือกของ class

```latex
\documentclass[final]{cskkuproject}
```

| ตัวเลือก | ผล |
|---|---|
| `progress1` / `progress2` / `final` | ชนิดเล่มบนปก: รายงานความก้าวหน้าครั้งที่ 1, 2 หรือฉบับสมบูรณ์ |
| `plainnumbering` | เลขหัวข้อแบบ 1. / 1.1 / 1.1.1 / (1) (ตัวอย่างหน้า 24 ของคู่มือ) |
| `boldheadings` | หัวข้อย่อยตัวหนา |
| `chapterfloats` | เลขภาพ ตาราง สมการ และโปรแกรมแยกตามบท (2.1, 2.2) แทนเลขต่อเนื่องทั้งเล่ม |
| `chapterpagenumber` | แสดงเลขหน้าในหน้าแรกของบท |
| `titleasis` | ไม่แปลงชื่อเรื่องภาษาอังกฤษบนปกเป็นตัวพิมพ์ใหญ่ |
| `englishbook` | เล่มภาษาอังกฤษทั้งเล่ม (Times) |
| `nobiblatex` | ไม่ใช้ biblatex (สำหรับเล่มเดิมที่ใช้ BibTeX) |
| `mermaid` | ใช้แผนภาพ Mermaid (ต้องเปิด `-shell-escape` และติดตั้ง Mermaid CLI) |

## หัวข้อและสารบัญ

| คำสั่ง | เลขหัวข้อ (ค่าเริ่มต้น) | ตัวเลือก `plainnumbering` | แสดงในสารบัญ |
|---|---|---|---|
| `\chapter` | บทที่ 1 | บทที่ 1 | ✔ |
| `\section` (หัวข้อใหญ่ 16 หนา) | 1.1 | 1. | ✔ |
| `\subsection` (หัวข้อย่อยระดับ 1) | 1.1.1 | 1.1 | ✔ |
| `\subsubsection` (ระดับ 2) | (1) | 1.1.1 | ✘ |
| `\paragraph` (ระดับ 3) | (1.1) | (1) | ✘ |

- หัวข้อแต่ละระดับเยื้องเข้าไปทีละขั้นตามตัวอย่างหน้า 24 ของคู่มือ ชื่อหัวข้อที่ยาวเกิน 1 บรรทัดจะขึ้นบรรทัดใหม่ตรงกับข้อความ ไม่ใช่ตรงกับเลข และย่อหน้าใต้หัวข้อเริ่มตรงกับชื่อหัวข้อ
- คู่มือกำหนดหัวข้อย่อยไว้ 3 ระดับใต้หัวข้อใหญ่ เนื้อหาที่ต้องแบ่งลึกกว่า `\paragraph` ให้เขียนเป็นรายการ `enumerate` (ถ้าใช้ `\subparagraph` จะได้หัวข้อไม่มีเลขพร้อมคำเตือน)
- สารบัญแสดงบท หัวข้อใหญ่ และหัวข้อย่อยระดับ 1 ตามคู่มือข้อ 13 ถ้าต้องการเฉพาะหัวข้อใหญ่ให้ใส่ `\setcounter{tocdepth}{1}` ใน `main.tex` (มีบรรทัดตัวอย่างไว้แล้ว)
- ภาคผนวกแสดงในสารบัญเฉพาะชื่อภาคผนวก ถ้าต้องการแสดงหัวข้อในภาคผนวกด้วยให้ใส่ `\renewcommand\cskkuAppendixTocDepth{1}` ใน `main.tex`
- ชื่อที่ยาวเกิน 1 บรรทัดในสารบัญ สารบัญตาราง สารบัญภาพ และสารบัญสมการ บรรทัดถัดไปเริ่มตรงกับข้อความของบรรทัดแรก และเลขหน้าอยู่ท้ายบรรทัดสุดท้ายพร้อมจุดนำ
- สารบัญที่ยาวเกิน 1 หน้า หน้าถัดไปมีชื่อ "สารบัญ (ต่อ)" และหัวคอลัมน์ "หน้า" ให้อัตโนมัติ (ใช้กับสารบัญตาราง ภาพ และสมการด้วย)

## วิธีเขียนเนื้อหา

**ภาพ** ชื่อภาพอยู่ใต้ภาพ

```latex
\begin{figure}[H]
\centering
\includegraphics[width=0.8\linewidth]{images/usecase.png}
\caption{Use case diagram ของระบบ}
\label{fig:usecase}
\end{figure}
```

ภาพยังไม่พร้อมให้ใช้กรอบชั่วคราว `\cskkuPlaceholder[ข้อความ]{กว้าง}{สูง}`

**ตาราง** ชื่อตารางอยู่เหนือตาราง ชิดซ้าย ใช้คอลัมน์ `L{กว้าง}` (ชิดซ้าย ตัดบรรทัดได้) และ `C{กว้าง}` (กลาง) เพื่อไม่ให้ตารางล้นหน้า ตารางยาวเกิน 1 หน้าใช้ `longtable` ระบบพิมพ์ชื่อตารางซ้ำพร้อม "(ต่อ)" ให้ (ดูตารางโครงสร้าง users ในบทที่ 4) ถ้าหัวข้อตามด้วย `longtable` ทันทีแล้วหัวข้อตกอยู่ท้ายหน้า template จะย้ายหัวข้อไปขึ้นหน้าใหม่พร้อมตารางเอง (ต้องคอมไพล์ 2 รอบ ซึ่ง Overleaf และ `latexmk` ทำให้อยู่แล้ว)

**รายการ** ใช้ `enumerate` ทุกรายการ (เลข 1) 2) ... ระดับที่สองเป็น a) b) ...) ไม่ใช้ `itemize` (•) และไม่ต้องใส่ `[label=...]` เพราะ template กำหนดรูปแบบให้แล้ว ข้อที่มีชื่อให้ชื่อเป็นตัวหนาแล้วขึ้นบรรทัดคำอธิบาย ส่วนข้อที่เป็นประโยคเขียนต่อจากเลขข้อได้เลย

```latex
\begin{enumerate}
  \item \textbf{ระบบสมาชิก}\\*
        สมัครสมาชิก เข้าสู่ระบบ และกำหนดบทบาทผู้ใช้
  \item ผู้ใช้ส่งเอกสารได้ครั้งละหลายไฟล์
\end{enumerate}
```

ไม่ต้องจัดระยะเองด้วย `\vspace` `\medskip` หรือ `\newline` ในเนื้อหา และไม่ต้องพิมพ์เลขนำหน้าชื่อหัวข้อเอง (template ใส่เลขหัวข้อให้) ระบบตรวจรูปเล่มของสาขาตรวจและปรับตามกติกาเหล่านี้

**โค้ดโปรแกรม** ใช้ `lstlisting` หรือ `\lstinputlisting{ไฟล์}` พิมพ์ภาษาไทยในความเห็นและข้อความได้ จัดบรรทัดโค้ดให้ยาวไม่เกินประมาณ 50 ตัวอักษรเพื่อไม่ให้ถูกตัดขึ้นบรรทัดใหม่ โค้ดสั้นที่ไม่ควรแยกหน้าให้ใส่ `\Needspace*{N\baselineskip}` ก่อน `lstlisting` (N = จำนวนบรรทัดของโค้ด + 1) โค้ดสั้นในบรรทัดใช้ `\cskkuCode{DATABASE_URL}` (ใช้ `_` ได้โดยตรง และตัดบรรทัดหลัง `/ . _ -` ได้)

**สมการ** สมการอยู่กึ่งกลาง เลขสมการในวงเล็บชิดขวา (1), (2), ... หรือ (3.1) เมื่อใช้ `chapterfloats`

```latex
ค่าเฉลี่ยคำนวณตามสมการที่~\eqref{eq:mean}      % -> สมการที่ (1)
\begin{equation}
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
\eqcaption{ค่าเฉลี่ยเลขคณิต}                   % ชื่อในสารบัญสมการ
\label{eq:mean}
\end{equation}
\begin{eqwhere}                                % เมื่อ x̄ คือ ... (จัดแนวให้)
\bar{x} & ค่าเฉลี่ยของคะแนน \\
n       & จำนวนผู้ตอบแบบสอบถาม
\end{eqwhere}
```

- สมการที่มี `\eqcaption` จะอยู่ใน "สารบัญสมการ" ต่อจากสารบัญภาพ ถ้าไม่มีสมการใดใช้ `\eqcaption` จะไม่สร้างหน้านี้
- หลายสมการต่อกันใช้ `align` (จัดแนวที่ `&`) และใส่ `\eqcaption` กับ `\label` ทีละบรรทัด บรรทัดที่ไม่ต้องการเลขใส่ `\nonumber`
- ข้อความภาษาไทยในสมการเขียนใน `\text{...}` เช่น `\text{ร้อยละ}` ส่วนฟอนต์สมการถูกย่อให้ขนาดเข้ากับ TH Sarabun New แล้ว
- สมการกับคำอธิบายที่ตามมา (เช่น `eqwhere`) จะไม่ถูกแยกไปคนละหน้า

**แผนภาพ** วาดด้วย TikZ ได้ในเล่ม (ตัวอย่างในบทที่ 3 และ 4) หรือส่งออกจากโปรแกรมอื่นเป็น PNG/PDF แล้วใช้ `\includegraphics`

**การอ้างอิงข้ามส่วน** `\label{...}` คู่กับ `ภาพที่~\ref{fig:usecase}` `ตารางที่~\ref{tab:fr}` `หัวข้อ~\ref{sec:design}`

## เอกสารอ้างอิง

- เพิ่มรายการใน `references.bib` แล้วอ้างในเนื้อหาด้วย `\cite{key}` → [1], `\cite{a,b,c}` → [1-3]
- เลขอ้างอิงเรียงตามลำดับที่อ้าง และหน้า "เอกสารอ้างอิง" พิมพ์เฉพาะรายการที่อ้าง
- รายการที่มีอักษรไทยจัดรูปแบบแบบไทยให้อัตโนมัติ: ชื่อผู้แต่งไทยเขียน `ชื่อ นามสกุล` และใช้ปี พ.ศ.
- เว็บไซต์ใช้ `@online` พร้อม `url` และ `urldate = {ปปปป-ดด-วว}` ระบบพิมพ์ "ค้นเมื่อ ... จาก ..." หรือ "Retrieved ..., from ..." ให้ตามภาษา
- ตัวอย่างแต่ละชนิด (วารสาร การประชุมวิชาการ วิทยานิพนธ์ หนังสือ เว็บไซต์) อยู่ใน `references.bib`

## ย้ายเนื้อหาจาก template เดิม (Template_Project_2026)

1. คัดลอกเนื้อหาจาก `chapter1.tex`–`chapter5.tex` เดิม มาวางในไฟล์ชื่อเดียวกันใน `chapters/` (ไฟล์ที่วางข้าง `main.tex` แบบเดิมก็ยังใช้ได้กับ `\chapterone`–`\chapterfive`)
2. คัดลอกข้อมูลโครงงานใน `main.tex` เดิมมาใส่ `main.tex` ใหม่ (ชื่อคำสั่งเหมือนเดิม และเพิ่ม `\projectCode`, `\submitMonthTH`, `\submitYearTH`, นักศึกษาคนที่ 3 และอาจารย์ที่ปรึกษาร่วม)
3. คำสั่งที่เปลี่ยน
   - `\maketitlepage` → `\makecover` และ `\makeinnercover`
   - ลบบรรทัด `\pagenumbering` และ `\ThaiAlph` เดิม ใช้ `\frontmatter` / `\mainmatter` แทน
   - `\tableofcontents` `\listoffigures` `\listoftables` → `\makecontents`
   - `\bibliographystyle{ieeetr}` + `\bibliography{references}` → `\addbibresource{references.bib}` (ก่อน `\begin{document}`) + `\printreferences`
   - `\appendiceschapter{ชื่อ}` ยังใช้ได้ หรือใช้ `\appendix` แล้ว `\chapter{ชื่อ}`
4. ตรวจ `references.bib`: เว็บไซต์เปลี่ยนจาก `howpublished={\url{...}}` + `note={Accessed: ...}` เป็น `@online` + `url` + `urldate` และชื่อผู้แต่งไทยเขียน `ชื่อ นามสกุล` โดยไม่มีจุลภาค
5. ปรับหัวข้อตามคู่มือข้อ 17: หัวข้อ 1.3 คือ "เป้าหมายและขอบเขต" (ข้อจำกัดของระบบย้ายไปหัวข้อ 5.2) และบทที่ 2 เริ่มด้วยงานวิจัยที่เกี่ยวข้อง แล้วจึงเป็นหลักการและทฤษฎี

เล่มที่ยังต้องการใช้ BibTeX แบบเดิมให้ใช้ `\documentclass[nobiblatex]{cskkuproject}` แต่รูปแบบรายการอ้างอิงจะเป็นของ style ที่เลือก ไม่ใช่รูปแบบในคู่มือ
