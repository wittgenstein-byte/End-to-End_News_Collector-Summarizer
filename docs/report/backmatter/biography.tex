\noindent\textbf{ชื่อ-นามสกุล}\quad นายนราวิชญ์ ศิริพล\\
\textbf{วัน เดือน ปีเกิด}\quad 15 กันยายน พ.ศ. 2546\\
\textbf{สถานที่เกิด}\quad จังหวัดขอนแก่น\\
\textbf{ประวัติการศึกษา}
\begin{enumerate}[noitemsep,topsep=0pt]
  \item พ.ศ. 2565 มัธยมศึกษาตอนปลาย โรงเรียนขอนแก่นวิทยายน จังหวัดขอนแก่น
  \item พ.ศ. 2566--ปัจจุบัน วิทยาศาสตรบัณฑิต สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น
\end{enumerate}
\noindent\textbf{ทุนการศึกษาและรางวัลที่ได้รับ}
\begin{enumerate}[noitemsep,topsep=0pt]
  \item ทุนการศึกษาโครงการพัฒนาอัจฉริยภาพทางวิทยาศาสตร์และเทคโนโลยีสำหรับเด็กและเยาวชน (JSTP)
  \item รางวัลรองชนะเลิศอันดับ 1 การแข่งขันพัฒนาโปรแกรมคอมพิวเตอร์แห่งประเทศไทย (NSC) ระดับภูมิภาค
\end{enumerate}

\vspace{0.8\baselineskip}

\noindent\textbf{ชื่อ-นามสกุล}\quad นายอัสดาวุฒิ เอื้อวงค์\\
\textbf{วัน เดือน ปีเกิด}\quad 28 กุมภาพันธ์ พ.ศ. 2547\\
\textbf{สถานที่เกิด}\quad จังหวัดอุดรธานี\\
\textbf{ประวัติการศึกษา}
\begin{enumerate}[noitemsep,topsep=0pt]
  \item พ.ศ. 2565 มัธยมศึกษาตอนปลาย โรงเรียนอุดรพิทยานุกูล จังหวัดอุดรธานี
  \item พ.ศ. 2566--ปัจจุบัน วิทยาศาสตรบัณฑิต สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น
\end{enumerate}
\noindent\textbf{ทุนการศึกษาและรางวัลที่ได้รับ}
\begin{enumerate}[noitemsep,topsep=0pt]
  \item ทุนการศึกษาผลการเรียนดีเด่น วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น ประจำปีการศึกษา 2567
  \item รางวัลชมเชย การแข่งขัน Hackathon นวัตกรรมเทคโนโลยีดิจิทัลเพื่อสังคม
\end{enumerate}
