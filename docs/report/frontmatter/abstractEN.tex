The exponential growth of online information and cross-outlet story redundancy often force readers to expend substantial time filtering and following news. This project presents the design and implementation of an automated, end-to-end news aggregation, classification, and text analytics pipeline. Architected in accordance with SOLID and GRASP design principles, the backend is developed using Python and FastAPI, utilizing Playwright headless browser instances to continuously ingest articles across 14 major Thai news publishers while leveraging multi-tier caching to optimize network utilization. The pipeline integrates key natural language processing capabilities, including automated story clustering to detect and group overlapping coverage across outlets, a deterministic trending algorithm that weights recency and publisher diversity without external LLM dependencies, and automated summarization and sentiment analysis powered by the KKU Gen.AI API, which provides concise highlights while embedding original source links to respect publisher copyrights. Article categorization into nine domain classes is achieved via a hybrid classifier combining contextual keyword cues with machine learning models. The responsive frontend is built with Vanilla JavaScript as a Single Page Application (SPA), delivering real-time updates via WebSocket (Socket.IO) and privacy-first client-side personalization conforming to PDPA standards (Zero-PII). The system successfully validated all 423 automated test cases across six architectural dimensions (100\% pass rate). Furthermore, a user acceptance study demonstrated strong adoption with an overall satisfaction score of 4.86 out of 5.00 and a 90.43\% recommendation rate, demonstrating that the platform substantially enhances reading efficiency and eliminates informational clutter.
