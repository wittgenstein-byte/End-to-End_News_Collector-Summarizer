\subsection{ชุดข้อมูลและการเตรียมข้อมูล (Datasets \& Data Preprocessing)}

การวิจัยและพัฒนาโมเดลจำแนกหมวดหมู่ข่าวภาษาไทย 9 หมวดหมู่หลัก (การเมือง, เศรษฐกิจ, เทคโนโลยี, สุขภาพ, สิ่งแวดล้อม, กีฬา, บันเทิง, สังคม, ต่างประเทศ) ใช้ชุดข้อมูลมาตรฐาน 2 แหล่งหลัก ได้แก่ ชุดข้อมูล ThaiSum ซึ่งเป็นคลังข้อมูลข่าวภาษาไทยขนาดใหญ่ที่รวบรวมจากสำนักข่าวชั้นนำ ได้แก่ ไทยรัฐ ไทยพีบีเอส เดลินิวส์ และประชาไท รวมกว่า 350,000 บทความ พร้อมการระบุหมวดหมู่และบทสรุปอย่างเป็นทางการ และชุดข้อมูล Prachathai-67k ซึ่งเป็นคลังข้อมูลบทความข่าวเชิงลึกด้านการเมือง สังคม และสิ่งแวดล้อม จำนวน 67,889 บทความ


กระบวนการเตรียมข้อมูล (Data Preprocessing Pipeline) เริ่มต้นจากการทำความสะอาดข้อความ ขจัดแท็ก HTML สัญลักษณ์พิเศษ และการเว้นวรรคซ้ำซ้อน จากนั้นทำการตัดคำภาษาไทยด้วยไลบรารี PyThaiNLP โดยใช้อัลกอริทึม \texttt{newmm} (Dictionary-based Maximal Matching ผสาน TCC) และคัดกรองคำหยุดภาษาไทยที่ไม่สื่อความหมายออก แล้วจึงแบ่งชุดข้อมูลออกเป็นชุดฝึกสอน ชุดตรวจสอบ และชุดทดสอบ (Stratified Train/Validation/Test Split) ในอัตราส่วน 70:15:15 เพื่อรักษาการกระจายตัวของทั้ง 9 หมวดหมู่ให้มีความสมดุล

\subsection{วิธีการฝึกสอนโมเดล (Model Training Methodology)}

ในการทดลองและฝึกสอนโมเดลจำแนกหมวดหมู่ข่าว ระบบได้ทำการพัฒนา 3 แนวทางหลัก ได้แก่ การประยุกต์ใช้โมเดล Linear Support Vector Classifier (LinearSVC) ร่วมกับการแปลงเวกเตอร์ข้อความด้วย \texttt{TfidfVectorizer} ที่กำหนดขนาดฟีเจอร์สูงสุด 20,000 คำ และผ่านการสอบเทียบความน่าจะเป็น (Probability Calibration) ด้วย \texttt{CalibratedClassifierCV} เพื่อให้ได้ค่าความเชื่อมั่นของแต่ละหมวดหมู่ การปรับจูนโมเดลการเรียนรู้เชิงลึก (Fine-tuned WangchanBERTa Transformer) บนสถาปัตยกรรม RoBERTa โดยเพิ่ม Linear Classification Head ด้านบน และฝึกสอนด้วย Cross-Entropy Loss ผ่าน AdamW Optimizer และการออกแบบไปป์ไลน์จำแนกแบบหลายชั้น (3-Tier Cascade Classifier) ในระบบจริง ซึ่งเริ่มจากการตรวจจับคำสำคัญเฉพาะกลุ่มที่มีความแม่นยำสูง (Tier 1: Regex \& Keyword Cues) หากความเชื่อมั่นไม่ถึงเกณฑ์จึงส่งต่อให้โมเดล LinearSVC ประมวลผล (Tier 2) และมีโมเดล WangchanBERTa ทำหน้าที่รองรับกรณีข้อความที่มีความกำกวมสูง (Tier 3)

\subsection{ระเบียบวิธีการประเมินความแม่นยำของการจัดกลุ่มข่าวข้ามสำนัก (Multi-Source Story Clustering Evaluation)}

เพื่อเตรียมการประเมินความถูกต้องของระบบการรวมข่าวหลายสำนักเป็นประเด็นเดียวกันตามข้อเสนอแนะของคณะกรรมการ โครงงานได้ออกแบบระเบียบวิธีและตัวชี้วัดสำหรับการทดสอบกับชุดข่าวจริง โดยเริ่มต้นจากการสร้างชุดข้อมูลทดสอบเหตุการณ์เด่นจาก 5 สำนักข่าวหลักในช่วงเวลาเดียวกัน พร้อมทั้งติดป้ายกำกับกลุ่มเหตุการณ์ (Event Cluster ID) โดยผู้เชี่ยวชาญ ครอบคลุมทั้งกรณีที่พาดหัวคล้ายกันและกรณีที่พาดหัวคนละมุมมอง สำหรับการวัดผลการจัดกลุ่มจะใช้ตัวชี้วัด Pairwise Precision ($P_{\text{pair}}$) เพื่อประเมินสัดส่วนคู่ข่าวที่ระบบจัดเข้ากลุ่มเดียวกันว่าเป็นเหตุการณ์เดียวกันจริงหรือไม่ ช่วยป้องกันความผิดพลาดจากการรวมข่าวคนละเหตุการณ์ (False Positives) และ Pairwise Recall ($R_{\text{pair}}$) เพื่อวัดความสามารถในการรวมคู่ข่าวที่เป็นเหตุการณ์เดียวกันได้อย่างครบถ้วน (ป้องกัน False Negatives) ร่วมกับค่า Pairwise F1-score ($F1_{\text{pair}}$) นอกจากนี้ ยังมีการประเมินความถูกต้องของฉันทามติหมวดหมู่ (Category Consensus Accuracy) โดยวัดความสอดคล้องระหว่างหมวดหมู่ระดับกลุ่มที่ได้จากอัลกอริทึม Majority Voting เปรียบเทียบกับหมวดหมู่ที่แท้จริงของเหตุการณ์ เพื่อยืนยันประสิทธิภาพในการแก้ไขปัญหาความไม่สอดคล้องของ Tag จากสำนักข่าวต้นทาง
