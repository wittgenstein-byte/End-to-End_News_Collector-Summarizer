\section{สรุปผลการดำเนินโครงงาน}

\subsection{ข้อจำกัดด้านแหล่งข้อมูลภายนอกและบริการโมเดลภาษาขนาดใหญ่}

ข้อจำกัดประการแรกสืบเนื่องมาจากโครงสร้างหน้าเว็บของสำนักข่าวต้นทางอาจมีการปรับเปลี่ยนโครงสร้าง DOM (DOM Mutation) ซึ่งส่งผลให้โมดูลแยกวิเคราะห์ (Parser) ต้องได้รับการปรับปรุงให้สอดคล้องกับโครงสร้างหน้าเว็บใหม่อย่างต่อเนื่อง นอกจากนี้ การสังเคราะห์เนื้อหาและบทสรุปข่าวยังพึ่งพาการเชื่อมต่อกับบริการ API ภายนอก ได้แก่ KKU Gen.AI ซึ่งในกรณีที่เกิดปัญหาความล่าช้าบนเครือข่ายหรือโควตาการเรียกใช้งานหมดลง ระบบต้องปรับเปลี่ยนการทำงานเข้าสู่โหมดการแสดงผลข้อความสรุปสำรองอัตโนมัติ (Heuristic Fallback) โดยใช้พาดหัวข่าวตัวแทนหลักแทน

\subsection{ข้อจำกัดด้านทรัพยากรการประมวลผล}

ในมิติด้านทรัพยากรระบบ การเปิดใช้งาน Playwright Headless Browser เพื่อสกัดข้อมูลจากเว็บไซต์ข่าวสารที่มีระบบป้องกันบอตหรือใช้การแสดงผลฝั่งไคลเอนต์ จำเป็นต้องใช้ทรัพยากรหน่วยความจำหลักและรอบการประมวลผลของ CPU สูงกว่าการดึงข้อมูลผ่านโพรโทคอล HTTP REST API ปกติ นอกจากนี้ การประมวลผลโมเดลภาษา WangchanBERTa เพื่อสร้างเวกเตอร์หนาแน่น 768 มิติบนเครื่องคอมพิวเตอร์แม่ข่ายที่ไม่มีหน่วยประมวลผลกราฟิก (GPU) อาจใช้ระยะเวลาในการประมวลผลบทความยาวเพิ่มขึ้นเล็กน้อย

\subsection{ข้อจำกัดด้านการรู้จำชื่อเฉพาะในบริบทภาษาไทย}

โมเดลการรู้จำชื่อเฉพาะ (Named Entity Recognition: NER) อิงตามคลังศัพท์และชุดข้อมูลที่ผ่านการฝึกฝนมาล่วงหน้าของ \texttt{thainer-v2} ส่งผลให้กรณีที่มีชื่อบุคคล สถานที่ หรือศัพท์สแลงเกิดใหม่ในกระแสข่าวสารปัจจุบัน โมเดลอาจไม่สามารถสกัดเอนทิตีดังกล่าวได้อย่างสมบูรณ์ ซึ่งส่งผลต่อคะแนนความคล้ายคลึงของเอนทิตีในแถบความคล้ายคลึงระดับกลาง (Ambiguity Band) เล็กน้อย

\subsection{การปรับปรุงฟังก์ชันการทำงาน}

สำหรับการพัฒนาฟังก์ชันการทำงานในระยะต่อไป ระบบสามารถขยายขีดความสามารถได้หลายด้าน ประการแรกคือการพัฒนาระบบตรวจสอบความสอดคล้องของข้อเท็จจริงข้ามสำนักข่าว (Cross-Source Fact Consistency Checking) เพื่อเปรียบเทียบความแตกต่างของตัวเลข สถิติ หรือแถลงการณ์ระหว่างสำนักข่าว และแจ้งเตือนจุดที่ข้อมูลขัดแย้งกันให้แก่ผู้อ่าน ประการถัดมาคือการพัฒนาระบบแจ้งเตือนข่าวด่วนเฉพาะบุคคลและการจัดทำจดหมายข่าวสรุปประจำวัน (Personalized Notifications \& Automated Daily Digest) โดยส่งสรุปประเด็นข่าวที่ผู้ใช้ให้ความสนใจผ่านทางอีเมลหรือเว็บแอปพลิเคชัน และประการสุดท้ายคือการขยายขีดความสามารถเพื่อรองรับข้อมูลข่าวสารแบบมัลติมีเดีย (Multi-Modal News Ingestion) เช่น การแปลงเสียงในคลิปรายงานข่าวเป็นข้อความ (Speech-to-Text) เพื่อนำมาประมวลผลร่วมกับข่าวบทความ

\subsection{การยกระดับสถาปัตยกรรมระบบสืบค้นข่าวสารแบบไฮบริด (Hybrid Search Architecture)}

จากการประเมินประสิทธิภาพการสืบค้นข่าวสารในสถานการณ์จริง คณะผู้พัฒนาขอเสนอแนะสถาปัตยกรรมที่เหมาะสมที่สุดสำหรับการสืบค้นข่าวสารภาษาไทยแบบผสมผสาน (Optimal Hybrid News Search Pipeline) เพื่อแก้ไขข้อจำกัดด้านความไม่สอดคล้องของคำศัพท์ (Vocabulary Mismatch) และความคลุมเครือของชื่อเฉพาะในภาษาไทย โดยแบ่งกระบวนการทำงานออกเป็น 2 ขั้นตอนหลัก ได้แก่

\begin{enumerate}
    \item \textbf{การเตรียมข้อมูลล่วงหน้า (Offline Preparation)}: การสร้างและปรับปรุงคลังแผนที่คำพ้องและนามแฝงเฉพาะทาง (Custom Aliases and Synonym Map) โดยมุ่งเน้นคำเฉพาะทางในแวดวงข่าวสารภาษาไทย ได้แก่ ฉายาและชื่อย่อตำแหน่งข้าราชการระดับสูง (เช่น ``ผบ.ตร.'', ``ปลัด มท.'', ``บิ๊กป้อม'') พรรคการเมือง (เช่น ``พท.'', ``ปชน.'', ``ภท.'') และองค์กรอิสระหรือหน่วยงานภาครัฐ (เช่น ``สตง.'', ``ป.ป.ช.'', ``กกต.'', ``ก.ล.ต.'') เพื่อให้ระบบเข้าใจความหมายที่ตรงกันโดยไม่ต้องพึ่งพาพจนานุกรมภาษาสากลเพียงอย่างเดียว
    
    \item \textbf{การประมวลผลคำค้นหาในเวลาจริง (Online Query Time)}: ดำเนินการสืบค้นแบบขนานสองแกน (Two-Pronged Hybrid Retrieval) ได้แก่
    \begin{itemize}
        \item \textbf{การสืบค้นเชิงคำศัพท์ (Lexical Search - BM25 with Query Expansion)}: ทำการขยายคำค้นหาของผู้ใช้ด้วย Custom Synonym Map แล้วสืบค้นด้วยอัลกอริทึม BM25 บนดัชนีเนื้อหาข่าว เพื่อการันตีความแม่นยำสูง (High Precision) สำหรับชื่อเฉพาะ (Named Entities) ตัวย่อหน่วยงาน และคีย์เวิร์ดตายตัว
        \item \textbf{การสืบค้นเชิงความหมาย (Dense Vector Search)}: แปลงคำค้นหาเป็นเวกเตอร์หนาแน่น (Dense Embedding) ผ่านโมเดลภาษา (เช่น WangchanBERTa) เพื่อค้นหาความใกล้เคียงในมิติความหมาย ช่วยดึงดูดข่าวที่มีบริบทแวดล้อมเกี่ยวโยงกัน แม้จะไม่ปรากฏคำค้นหาตรงตัวก็ตาม ซึ่งช่วยเพิ่มความครอบคลุมของเนื้อหา (High Recall)
    \end{itemize}
    หลังจากนั้น นำผลลัพธ์จากทั้งสองกระบวนการมารวมอันดับ (Rank Fusion) ด้วยวิธี Reciprocal Rank Fusion (RRF) เพื่อรวมลำดับอย่างเป็นกลางโดยไม่ต้องปรับสเกลคะแนนดิบ หรือส่งต่อให้ Cross-Encoder Reranker ทำการคำนวณปฏิสัมพันธ์เชิงลึกระหว่างคำค้นหาและเนื้อหาข่าว ทำให้ได้ผลลัพธ์การสืบค้นที่มีทั้งความแม่นยำของชื่อเฉพาะ (Precision) และความครอบคลุมของบริบทที่เกี่ยวโยงกัน (Recall) ในระดับสูงสุดสำหรับการค้นหาข่าวจริง
\end{enumerate}

\subsection{แนวทางการวิจัยต่อยอด}

ในเชิงการวิจัยต่อยอด คณะผู้พัฒนาเล็งเห็นแนวทางสำคัญ 2 ประการ ประการแรกคือการวิจัยเพื่อปรับแต่งค่าไฮเปอร์พารามิเตอร์แบบพลวัต (Dynamic Hyperparameter Optimization) สำหรับอัตราการสลายตัวของเวลา ($\tau$) และน้ำหนักของ Centroid EMA ($\alpha$) ตามความเร็วเฉลี่ยของการนำเสนอข่าวในแต่ละหมวดหมู่ โดยใช้เทคนิคการเรียนรู้แบบเสริมกำลัง (Reinforcement Learning) หรือ Bayesian Optimization เพื่อให้สอดคล้องกับพฤติกรรมข่าวที่เปลี่ยนไปตามกาลเวลา และประการที่สองคือการวิจัยโมเดลจำแนกอคติและจุดยืนของสำนักข่าว (Media Bias \& Stance Detection) เพื่อวิเคราะห์ความสมดุลและความเป็นกลางในการนำเสนอข่าวของสำนักข่าวต่าง ๆ ในประเทศไทยอย่างเป็นวิทยาศาสตร์
