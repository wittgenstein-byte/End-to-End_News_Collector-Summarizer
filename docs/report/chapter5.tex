\section{สรุปผลการดำเนินโครงงาน}
% -----------------------------------------------------------

โครงงาน ``ระบบจำแนกและวิเคราะห์ข่าวสารอัตโนมัติด้วยเทคนิคการประมวลผลภาษาธรรมชาติแบบเฉพาะประเภท'' ได้ดำเนินการพัฒนาเสร็จสิ้นตามขอบเขตและข้อกำหนดที่วางไว้ โดยสามารถรวบรวมข่าวสารจากหลากหลายแหล่ง สรุปเนื้อหาและวิเคราะห์อารมณ์ของข่าวด้วย Large Language Model (KKU Gen.AI) จำแนกหมวดหมู่ข่าวภาษาไทยด้วยเทคนิค Thai NLP และแสดงผลแบบเรียลไทม์ผ่าน WebSocket พร้อมระบบแนะนำข่าวสาร ผลการดำเนินงานสรุปเปรียบเทียบกับวัตถุประสงค์ได้ดังตารางที่ \ref{tab:obj_result}

\section{ข้อจำกัดของระบบ}
% -----------------------------------------------------------

\subsection{ข้อจำกัดด้านแหล่งข้อมูลภายนอก}

\begin{enumerate}[label=\arabic*)]
    \item โครงสร้างหน้าเว็บของสำนักข่าวต้นทางอาจมีการเปลี่ยนแปลง (DOM mutation) ซึ่งอาจทำให้ตัวแยกวิเคราะห์ (Parser) ต้องได้รับการปรับปรุงให้ตรงกับโครงสร้างใหม่
    \item การสรุปเนื้อหาข่าวพึ่งพา API ภายนอก (KKU Gen.AI / LLM API) หากเกิดปัญหาเครือข่ายหรือหมดโควตา ระบบจะทำงานในโหมดข้อความสรุปตั้งต้นแทน
\end{enumerate}

\subsection{ข้อจำกัดด้านทรัพยากรและการประมวลผล}

\begin{enumerate}[label=\arabic*)]
    \item การเปิดใช้งาน Playwright Headless Browser ในการดึงเว็บไซต์ที่ซับซ้อนใช้หน่วยความจำและ CPU มากกว่าการดึงข้อมูลผ่าน HTTP REST API แบบปกติ
\end{enumerate}

\section{ข้อเสนอแนะในการพัฒนาต่อไป}
% -----------------------------------------------------------

\subsection{การปรับปรุงฟังก์ชันการทำงาน}

\begin{enumerate}[label=\arabic*)]
    \item \textbf{การรองรับฐานข้อมูลแบบ Distributed:} พัฒนา Adapter สำหรับเชื่อมต่อ MongoDB หรือ PostgreSQL เพิ่มเติมจาก \texttt{FileNewsRepository} เพื่อรองรับปริมาณข่าวขนาดใหญ่
    \item \textbf{ระบบสมาชิกและการซิงค์ข้ามอุปกรณ์:} พัฒนาระบบบัญชีผู้ใช้เพื่อซิงค์บุ๊กมาร์กและความสนใจข้ามอุปกรณ์
\end{enumerate}

\subsection{แนวทางการวิจัยต่อยอด}

\begin{enumerate}[label=\arabic*)]
    \item \textbf{การประยุกต์ใช้โมเดล Transformer ภาษาไทยเฉพาะทาง:} นำโมเดล WangchanBERTa มา Fine-tune กับชุดข้อมูลข่าวไทยเฉพาะทางเพื่อยกระดับความแม่นยำในการจำแนกหมวดหมู่แบบ Multi-label
    \item \textbf{การตรวจจับข่าวปลอมและการเปรียบเทียบมุมมอง (Cross-source Fact Verification):} พัฒนาโมดูลวิเคราะห์ข่าวเรื่องเดียวกันจากหลายสำนักข่าวเพื่อเปรียบเทียบความถูกต้องและความเป็นกลางของเนื้อหา
\end{enumerate}
